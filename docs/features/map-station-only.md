# 线路地图：选中站点时只画本站区块 / Draw Only the Focused Station

- 状态：**Approved**（Product Owner 2026-11-24 “可以，你试试”，同日授权实现）
- 关联：`docs/features/route-map.md`、`docs/features/map-zip-labels.md`
- 编号前缀：MSO

## 1. 背景与目标

PO 反馈：拖动、放大缩小时，很多色块延迟跟上。

现在选片区时整片区的 ZIP 区块都画在地图上（南加 742 块、北加 445 块）；选中站点后其他站点的区块仍在，只是用 `POLYGON_STYLE.outside`（填充 0.05）淡化。每次缩放 Leaflet 都要重新投影、重绘全部 SVG path。

Claude 2026-11-24 在 3200 实测（南加，选中 LAX02，缩放级别 10，不带动画的 `setZoom` 同步耗时）：

| 情况 | path 数 | 每次缩放耗时 |
|---|---|---|
| 全部区块都在地图上 | 742 | 99–134 ms |
| 只留 LAX02 的区块 | 127 | 25–44 ms |

目标：选中站点时地图上只放本站区块，缩放 / 拖动重绘量按站点大小而不是片区大小。

## 2. 规则

| 编号 | 规则 |
|---|---|
| MSO-D1 | 选中具体站点时，区块图层只包含该站点的 ZIP；其他站点的区块不加到地图上（不是隐藏或透明，而是不在 DOM 里）。 |
| MSO-D2 | 选“全部站点（片区总览）”时，行为与现在相同，全部区块都画。 |
| MSO-D3 | 片区数据仍按片区一次请求并缓存（`districtCache`）；在同片区内切换站点不重新请求，只切换地图上的区块。 |
| MSO-D4 | 搜索邮编 / 点击结果时，如果这个 ZIP 属于**同片区的另一个站点**，自动把站点切到那个站点，再选中并定位该 ZIP（PO 2026-11-24 同意）。跨片区的现有提示（“该 ZIP 属于 …”）不变；`multi_station` 等现有特殊情况保持现状。 |
| MSO-D5 | 线路编号、邮编标注、选中描边、图例统计、悬停 / 提示、DSP 筛选、区块深浅滑块在只画本站时表现与现在一致（它们本来就只针对本站）。 |
| MSO-D6 | 只改前端：不改 API、store、schema、数据。 |

## 6. MSO-P2：底图缩放后先画看得见的部分（Product Owner 2026-11-24 “先做方案 A”）

### 6.1 背景（Claude 2026-11-24 在 3200 实测）

只画本站后，PO 反馈缩放仍有延迟。南加 LAX02、缩放级别 10↔12、放大或缩小一级：

| 部分 | 耗时 |
|---|---|
| 区块（MSO-T1 后）同步重绘 | 约 35–95 ms |
| 底图图块 | 每次 35–67 张，全部画完 0.75–1.6 s；主线程被连续占用最长约 0.9 s |

原因：底图是 protomaps 矢量瓦片，在浏览器主线程实时绘制；8 个底图层（`web/basemap-layers.js` 的 `basemaps`），并且 `BASEMAP_PREFETCH = 0.25` 让每次缩放除了视口还要多画四周一圈（面积约 2.25 倍）。滚轮连续缩放时，每个中间级别也都会触发整套图块绘制。

方案 B（预先生成栅格底图）暂不做，A 做完后 PO 再评估。

### 6.2 规则

| 编号 | 规则 |
|---|---|
| MSO-D7 | 缩放 / 拖动结束后，底图**先只画视口内**的图块；视口外的预取圈（`BASEMAP_PREFETCH`）在地图静止一段时间（可配置常量，建议 300–500 ms）后再补画。补画前又开始移动 / 缩放时，取消这次补画。 |
| MSO-D8 | 连续缩放（滚轮多格、连续点 +/-）时，中间级别不画底图图块：缩放停下一段时间（可配置常量，建议约 200 ms）后才为最终级别建图块。期间沿用 Leaflet 缩放动画缩放旧图块。 |
| MSO-D9 | 只改底图图块的调度时机，不改底图样式、数据、区域划分、`_isValidTile` 规则、`LABEL_TILE_CAP`；区块、标签、仓库标记不受影响。 |
| MSO-D10 | 新常量集中在 `web/basemap-layers.js` 顶部（与 `BASEMAP_PREFETCH` 一起），注释写明用途。 |

## 5. 实现记录

MSO-T1：`render` 时为整片区建好全部 layer 并缓存在 `allLayers`；`updateStationLayers()` 按当前站点从 `polygons` 增删 layer，`layers` 只保留地图上的本站区块，并重建本站线路编号与邮编标注。同片区切站复用缓存 layer，不重新请求、不重建 geometry。跨站 ZIP 搜索复用 `changeStation()`（含保存站点偏好），切站后检查搜索序号，避免旧搜索覆盖新搜索。选择“缓存 + 增删”而不是每次重建，是为了切站时不重复解析几何和绑定事件。

Claude 2026-11-24 在 3200 复测（南加）：全部站点 742 个 path，LAX02 127 个，SAN01 80 个；同片区切站 0 次新的 district 请求；缩放级别 10 每次缩放同步耗时 LAX02 为 30–42 ms，全部站点为 104–121 ms（MSO-AC5 满足）。在 LAX02 搜 SAN01 的 ZIP 91902：站点自动切到 SAN01，ZIP 选中并描边；控制台无错误。全套测试 970 项通过（第一次运行有 1 项偶发失败，重跑通过）。

MSO-T2：底图先按视口建图块；地图静止 `BASEMAP_PREFETCH_DELAY_MS`（400 ms）后，把范围向四周扩大 `BASEMAP_PREFETCH`（25%），并调用各底图层的 `_update()` 补建预取圈；`movestart` / `zoomstart` 时关闭预取并取消待执行的补画。用到 Leaflet GridLayer 内部方法 `_getTiledPixelBounds` 和 `_update`，升级 Leaflet 时要复查。Leaflet 1.9.4 的 `_pruneTiles` 会在 `keepBuffer: 4` 范围内保留已画的图块，所以关闭预取后，已画的预取圈不会马上被删掉造成闪白；缩放级别变化或视图重置时旧图块仍按 Leaflet 原逻辑移除。D8 移到 MSO-T3。（Codex 原记录交接时出现乱码，2026-11-24 由 Claude 重写。）

Claude 2026-11-24 在 3200 复测（南加 LAX02，缩放级别 10↔12，不带动画的 `setZoom`）：

| 指标 | 改动前（6.1） | MSO-T2 后 |
|---|---|---|
| 视口内底图画完 | 全部图块 0.75–1.6 s 才画完 | 一般 0.1–0.22 s，最慢一次 0.58 s |
| 主线程最长连续占用 | 最长约 0.9 s | 35–189 ms |
| 首批图块数 | 35–67（含预取圈） | 20–41（只含视口） |

预取圈在约 0.4 s 后补画，全部画完约 0.5–0.7 s。MSO-AC9 满足。全套测试 970 项通过。
